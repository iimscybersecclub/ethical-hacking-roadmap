# 📚 Learning Resources

This document contains a curated list of free and high-quality resources to help you through your 6-month journey. Bookmark these!

---

## 🎓 Interactive Lab Platforms (Must Use)

These platforms provide legal, safe environments to practice hacking.

* **[TryHackMe](https://tryhackme.com/)**: The best place for beginners. Follow their "Complete Beginner" and "Web Fundamentals" learning paths.
* **[Hack The Box (HTB)](https://www.hackthebox.com/)**: Harder than TryHackMe, but excellent for real-world scenarios. Use their free "Starting Point" machines.
* **[PortSwigger Web Security Academy](https://portswigger.net/web-security)**: The absolute gold standard for Web Application Security. Created by the makers of Burp Suite. Completely free.
* **[PicoCTF](https://picoctf.org/)**: Created by Carnegie Mellon University. Excellent for absolute beginners to learn CTF basics.
* **[OverTheWire (Bandit)](https://overthewire.org/wargames/bandit/)**: The best way to learn the Linux command line hands-on.

---

## 📖 Official Documentation & Reading

* **[OWASP Foundation](https://owasp.org/)**: The Open Worldwide Application Security Project. Read the [OWASP Top 10](https://owasp.org/www-project-top-ten/).
* **[MDN Web Docs](https://developer.mozilla.org/en-US/)**: The ultimate resource for learning HTML, CSS, JavaScript, and HTTP fundamentals.
* **[Linux Journey](https://linuxjourney.com/)**: A fantastic, interactive guide to learning Linux from scratch.
* **[Cisco Skills For All](https://skillsforall.com/)**: Great free courses on networking basics (Networking Academy).
* **[FreeCodeCamp](https://www.freecodecamp.org/)**: Excellent for learning Python, Web Development, and basic Information Security.

## 📺 YouTube Channels

Video content is great for understanding complex concepts. Subscribe to these channels:

### For General Cybersecurity & Mentorship
* **[NetworkChuck](https://www.youtube.com/c/NetworkChuck)**: Energetic, great for networking basics, Linux, and getting excited about tech.
* **[The Cyber Mentor (TCM Security)](https://www.youtube.com/c/TheCyberMentor)**: Incredible full-length courses (like the "15 Hour Ethical Hacking Course"). Very practical.
* **[John Hammond](https://www.youtube.com/c/JohnHammond010)**: Excellent malware analysis, CTF walkthroughs, and security news.

### For Deep-Dive Technical Knowledge
* **[Computerphile](https://www.youtube.com/user/Computerphile)**: Deep dives into how algorithms, encryption, and computer systems actually work.
* **[Practical Networking](https://www.youtube.com/c/PracticalNetworking)**: The best channel for understanding subnetting, the OSI model, and how networks function.
* **[Professor Messer](https://www.youtube.com/c/professormesser)**: The go-to resource for CompTIA Security+ and Network+ study groups.
* **[freeCodeCamp.org](https://www.youtube.com/c/Freecodecamp)**: Search their channel for full 10+ hour courses on Python, Linux, and Ethical Hacking.

## 💡 What to do if you feel stuck?

1. **Google is your best friend**: Literally every hacker Googles things daily. Try formatting searches like `how to bypass XSS filter site:stackoverflow.com`.
2. **Read the Manual (RTFM)**: Use the `man` command in Linux (e.g., `man nmap`) or check official docs.
3. **Take a Break**: Step away from the screen for 30 minutes. Fresh eyes find bugs.
4. **Join a Community**: Join Discord servers (like TryHackMe's or TCM Security's) and politely ask for help (share what you've already tried!).
