# 💻 Hands-on Labs & Exercises

Theory is important, but practical execution is how you actually learn. Below is a structured list of labs to complete alongside your roadmap.

---

## Month 1: Networking & Linux Labs
*   **Linux Command Line Training:** Complete levels 0 to 15 on [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/).
*   **Wireshark Basics:** Download a sample PCAP file from [Malware-Traffic-Analysis](https://www.malware-traffic-analysis.net/) and try to identify the victim's IP address and the malicious website they visited.
*   **TryHackMe:** Complete the "Linux Fundamentals" Part 1, 2, and 3 rooms.

## Month 2: Scripting Labs
*   **Regex Practice:** Use [Regex101](https://regex101.com/) to write regular expressions that can extract all IP addresses and email addresses from a block of text.
*   **API Interactions:** Use Python's `requests` library to pull data from a public API (like a weather API) and print specific values to your terminal.

## Month 3: Security & Crypto Labs
*   **Hashing Practice:** In your Linux terminal, create a text file. Generate its MD5 and SHA-256 hash. Change one letter in the text file and observe how the hashes completely change (The Avalanche Effect).
*   **TryHackMe:** Complete the "Intro to Security" and "Cryptography for Beginners" rooms.

## Month 4: Web Security Labs (PortSwigger)
Create a free account on [PortSwigger Web Security Academy](https://portswigger.net/web-security) and complete the "Apprentice" level labs for:
*   SQL Injection
*   Cross-Site Scripting (XSS)
*   Authentication bypass
*   File path traversal

## Month 5: Tool Mastery Labs
*   **Nmap:** Use TryHackMe's "Nmap" room to practice different scan types.
*   **Burp Suite:** Complete the "Burp Suite Basics" and "Burp Suite Repeater" rooms on TryHackMe.
*   **Directory Busting:** Setup a local vulnerable web server (like OWASP Juice Shop) and use Gobuster to find hidden directories.

## Month 6: Full CTF Practice
Complete these beginner-friendly rooms on TryHackMe without relying heavily on walkthroughs:
*   [Blue](https://tryhackme.com/room/blue) (Windows Exploitation)
*   [Ice](https://tryhackme.com/room/ice)
*   [Pickle Rick](https://tryhackme.com/room/picklerick) (Web & Linux PrivEsc)
*   [Basic Pentesting](https://tryhackme.com/room/basicpentestingjt)

**Tip:** If you get stuck on a CTF for more than 2 hours, it is okay to look at a writeup to get a hint. Learn from the hint, and then continue on your own!
