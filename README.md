## 📅 Study Plan & Daily Routine

To succeed in this 6-month journey, aim for **15–20 hours per week** of study and hands-on practice. Consistency is key!

### Recommended Schedule

**Weekdays (1-2 Hours/Day)**
- **Morning (30 mins):** Read an article, watch a short video, or review notes.
- **Evening (1-1.5 hours):** Follow tutorials, write code, or complete a TryHackMe/Hack The Box module.

**Weekends (4-6 Hours/Day)**
- **Deep Dive (2-3 hours):** Tackle complex topics (e.g., networking, web vulnerabilities).
- **Hands-on Labs (2-3 hours):** Complete CTFs, build projects, or write automation scripts.
- **Review:** Document your findings in the `notes/` folder.

## 🗺️ 6-Month Overview

Here is a high-level overview. For the detailed week-by-week breakdown, check out [roadmap.md](./roadmap.md).

* **Month 1: IT & Networking Foundations** - Understand how computers communicate (OSI, TCP/IP, Linux basics).
* **Month 2: Coding & Scripting** - Learn Python, Bash, and Web Basics (HTML/JS/APIs).
* **Month 3: Security Fundamentals** - Learn the CIA triad, cryptography, and threat modeling.
* **Month 4: Web Application Security** - Dive into OWASP Top 10 (SQLi, XSS, CSRF).
* **Month 5: Tools of the Trade** - Master Nmap, Wireshark, Burp Suite, and basic exploitation.
* **Month 6: Practical Pentesting & Job Prep** - CTFs, Capstone Project, Reporting, and Resume building.

## 🎯 Measurable Checkpoints

How do you know you are making progress? Use this checklist:

- [ ] **Month 1 Checkpoint:** Can you confidently navigate a Linux terminal and explain the TCP/IP handshake?
- [ ] **Month 2 Checkpoint:** Can you write a Python script to automate a simple task (like pinging a host)?
- [ ] **Month 3 Checkpoint:** Do you understand symmetric vs. asymmetric encryption and the CIA triad?
- [ ] **Month 4 Checkpoint:** Can you identify and exploit a basic SQL injection or XSS vulnerability in a lab?
- [ ] **Month 5 Checkpoint:** Are you comfortable running Nmap scans and intercepting traffic with Burp Suite?
- [ ] **Month 6 Checkpoint:** Have you completed 10+ CTFs and written your Capstone Pentest Report?

## 🚧 Common Beginner Mistakes (And How to Avoid Them)

1. **Skipping the Basics:** Don't jump straight into hacking. If you don't understand how a network works, you won't understand how to break it. *Solution: Spend ample time in Month 1.*
2. **Watching Without Doing:** Tutorial hell is real. *Solution: For every hour of watching, do two hours of hands-on labs.*
3. **Getting Overwhelmed:** Cybersecurity is massive. *Solution: Stick to this roadmap. Don't learn everything at once.*
4. **Not Taking Notes:** You will forget commands. *Solution: Use the `notes/` directory to document everything.*
5. **Breaking the Law:** *Solution: ONLY hack systems you have explicit permission to test (like TryHackMe or your own local VMs).*

## 🚀 Career Roadmap (After Completion)

Once you complete this roadmap, where do you go next?

1. **Security Operations Center (SOC) Analyst (Tier 1):** The most common entry-level role. You will monitor networks, analyze alerts, and respond to incidents.
2. **Junior Penetration Tester:** Test applications and networks for vulnerabilities. (Requires strong hands-on skills and a good portfolio).
3. **Security Engineer:** Build and maintain secure infrastructure.
4. **Bug Bounty Hunter:** Freelance hacking for rewards (great for building a resume).
